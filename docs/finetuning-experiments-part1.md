## 一、主线三判

1. **Route A(encoder LoRA):证伪 −49%**(§3)。peft LoRA(r=8/α=16)打在 encoder 的 qkv/proj/fc1/fc2,150 样本协议:psnr 9.50→7.41(−2.09 dB)、lpips 0.3414→0.4545、val/loss +49.3%。失效机制:高斯尺度爆炸(屏幕覆盖 1821×,0.349% 顶死 clamp)——给 ~158M 冻结 matching/pointmap 头喂 OOD 特征所致;这也是 OOM 与 illegal-memory-access 史的因果解释。单向 clamp 棘轮(越界处梯度为零)是加重 bug。
2. **Route B(冻结 encoder、只训 Gaussian head):证实 +1.00 dB**(§5)。完全照搬 upstream 配方,可训练 40.4M/729M(5.54%),峰值 6.3 GiB(vs LoRA 42 GiB)。epoch 0 即超 base。
3. **Route C(LPIPS 权重 0.25→1.0):通过但收益小**(§6)。−0.15 dB psnr 换 −0.0055 lpips;B、C 图像肉眼不可分;更重要的观察:**余量在"训更久"**——40-epoch 全线 +1.78~+3.69 dB(§8)。

## 二、测量协议(所有判定的地基,§2)

- **固定索引≠固定样本**:`__getitem__` 每次重新采样视图三元组,同一 base 三次评估 psnr 散布 **≈0.6 dB**(9.7268/9.8648/10.3221)。修复:评估前同时 seed random+torch 并快照/恢复。一切 per-epoch 判读的噪声标尺。
- 协议关闭的六类失败模式:无绝对锚点、跨配置比较、样本量不足、换尺子、抽样不可复现、只看标量不看图。
- **两套 psnr 绝对尺度**:旧尺度(TUM base 10.3221)与修正尺度(15.0911,通道归一化修正);Δ 一致,引用绝对值必须注明尺度。**所有 LPIPS 均为 AlexNet 口径**('vgg' 参数被误绑到 pretrained;VGG 重测域内头条从 −10.2% 缩到 −3.6%)。

## 三、SLAM 级验证(§9)

- **ATE 位级不变**(三条序列轨迹字节级相同):冻结 encoder ⇒ 特征/匹配/跟踪/位姿图不动,从推断升格为测量。
- **地图质量 +0.90 dB、Gaussian 数 −16%**(desk +1.73 / room +0.76 / 360 +0.22;lpips −6.5%)。每对增益 +1.78 衰减到地图上 +0.90(地图平均数十个关键帧)。
- **跨家族泛化仅限域内**(§11):对角线大幅改善,非对角 lpips 几乎全面恶化(最差 euroc-head→TUM −2.09 dB)。**这是域适配,不是普遍改进。**

## 四、3DGS 细化系列与自我纠偏(§10,全文最长的纠偏链)

- SLAM 地图初始化 vs 随机初始化:修复后的干净对照下,desk 差距衰减到**非零平台 ~+1.3~1.7 dB、lpips ~+17~19%**;随机对照臂曾被证实"在高斯数量级上退化"(7.35M 个 opacity=0.1 永久冻结)。
- **map 臂 ~50 视图饱和**是整个扫描最稳健的发现;**细化的 +6.7 dB 纯是光度的**(深度 L1 反而 +7%),head 微调**确实改善几何**(L1 −27%)——两者作用于不同轴。
- **模糊不是损失设计问题**(§10.11):扰动实验证明 MSE 才是奖励模糊的项、LPIPS 是唯一抗模糊的项(净惩罚 30:1);"LPIPS 导致模糊"假说被决定性否证。**出路是更多信息而非更好损失。**
- 纠偏史教训:六层自我纠正各自在不同代码状态下测量——**每个探针必须记录 git hash**;三次"plateau"判读全部被推翻,论文只报"best-so-far 及所在 epoch"。

## 五、可部署性论证(§13.1–13.13,核心反转)

- **三阶段阶梯**:stage 1 head 微调(已饱和)→ stage 2 SLAM 前馈(12.44)→ stage 3 在线地图优化(离线测得 14.00~14.73)。stage 1 增益大半与 stage 3 冗余;300 轮在线细化(数秒)买 +1.63 dB。
- **视图数在 ~25 饱和**(可部署杠杆只有 ~+0.45 dB,而 oracle 下是 2.43 dB);**位姿质量是唯一乘性闸门**(缺口 1.8 dB@14 视图 → 4.5 dB@50 视图),视图被锁在门后。
- **位姿 LR 是感知-失真旋钮**:1e-3 是海绵(误差 +88%),**1e-4 是真精修**(+0.72 dB 且 lpips 好 5.7%,但仅 desk 复现;room ±0.005 不复现)。
- **FramePoseLog 建成**(§13.10):逐帧位姿相对锚定关键帧持久化(`<seq>_frames.txt`),解锁全部非关键帧监督;非关键帧位姿是系统里最差的位姿(0.0291 vs 0.0170 m)。
- **共适应在烘焙瞬间产生**(§13.12b/§13.13,决定性):同一注入扰动下,GT 位姿构建的地图恢复 +51.8%,SLAM 估计位姿构建的地图 **−22.2%(主动拉离真值)**。这是 P1"永不烘焙、关键帧局部存储"设计的直接由来。
- **CUDA 相机梯度**:建成并验证(梯度相对误差 7.6e-06),顺带揪出 vendored rasterizer 的 sh[14] SH 后向 bug;但论证被削弱——25 视图饱和后非实时必需。运行间噪声地板 **~0.086 dB**(atomicAdd 求和顺序),废除"单次运行值/峰值摘取"。
- **离线天花板**:GT 位姿 30k 轮 ~19.95;天花板不在泛化也不在覆盖,而在表示/优化/测量。**到 ~19 的全部剩余缺口都是位姿。**

## 六、贯穿全文档的 10 个最重要数字

1. **−2.09 dB / val/loss +49.3%** — Route A 证伪幅度(§3)
2. **+1.00 dB(10.3221→11.3217)** — Route B 同抽样本锚点(§2.1/§5)
3. **≈0.6 dB** — 未 seed 评估的采样噪声带,一切判读的标尺(§2.1)
4. **1821× 屏幕覆盖** — 尺度爆炸签名,OOM/崩溃史机制(§3.1)
5. **+1.78 dB(TUM 40ep)/ +3.69 dB(EuRoC)** — "训更久"是全线最大单一杠杆(§8)
6. **ATE 恰好 0 + 地图 +0.90 dB、Gaussian −16%** — 增益存活到 SLAM 级(§9)
7. **~0.086 dB** — 运行间噪声地板(§13.11)
8. **位姿缺口 1.8→4.5 dB;可部署视图杠杆仅 ~+0.45 dB** — 位姿是唯一闸门(§13.10)
9. **57.7% vs 8.2–14.7%(冻结 vs 联合);GT 图 +51.8% vs SLAM 图 −22.2%** — 共适应证据(§13.12d/§13.13)
10. **12.44→14.71 dB(+2.3,lpips 同优)** — 可 ship 的 stage-3 配方,但仅 desk、全离线(§13.12)

**元 caveat(评审任何数字前必读)**:① 两套 psnr 尺度不可混引;② LPIPS 全部 AlexNet 口径;③ 每个 psnr 带 ~0.09 dB 地板;④ 多个结论为 desk 单场景;⑤ Sim3 对齐残差(0.0149m)约为位姿效应量的 60%,est-vs-GT 比较继承该仪器误差。
